# CPP-Library-Management-Project

# 📚 C++ Program – Library Management System Using Abstraction & Polymorphism

This project is a simple **Library Management System** developed in **C++** using:

- Abstract Class
- Pure Virtual Functions
- Inheritance
- Polymorphism
- Exception Handling
- Dynamic Memory Allocation

The system allows users to manage:

- Books
- DVDs
- Magazines

```txt

1. Add Book
2. Add DVD

4. Display All Items
5. Check Out Item
6. Return Item
```
